# @rnw-community/react-native-payments-example

Private example package for [@rnw-community/react-native-payments](../react-native-payments/readme.md). It proves the library on
both integration paths from a single shared codebase.

```
packages/react-native-payments-example
├── src              shared screens and payment builders (exported as `App`)
└── apps
    ├── bare         React Native CLI target with checked-in ios/ and android/
    └── expo         Expo target, native projects generated by `expo prebuild`
```

Both app targets depend on the shared `src` through the package name
`@rnw-community/react-native-payments-example` and consume `@rnw-community/react-native-payments` from workspace source.

## Running the app targets

Run from the repository root:

```bash
yarn workspace @rnw-community/react-native-payments-example ios:bare
yarn workspace @rnw-community/react-native-payments-example android:bare
yarn workspace @rnw-community/react-native-payments-example ios:expo
yarn workspace @rnw-community/react-native-payments-example android:expo
```

Metro can be started separately with `start:bare` / `start:expo`. The Expo native projects are regenerated on demand with
`prebuild:expo` and are not committed.

## App

The shared entry point renders the payment demo screen: wallet availability check, a delayed-abort payment, and a form toggling
`requestBillingAddress`, `requestPayerEmail`, `requestPayerName`, `requestPayerPhone`, `requestShipping` and display items.

```js
import { registerRootComponent } from 'expo';

import { App } from '@rnw-community/react-native-payments-example';

registerRootComponent(App);
```

The Expo target also runs on the web (`yarn workspace @rnw-community/react-native-payments-example-expo web`), where the
library falls back to the W3C Payment Request API.

## iOS notes

The Apple Pay merchant identifier used by the demo is `merchant.react-native-payments`. For the bare target it has to match the
Apple Pay capability configured in Xcode; for the Expo target it is set by the `@rnw-community/react-native-payments/app.plugin`
entry in `apps/expo/app.json`.
